# Java Code Checker

A simple Java tool to check and improve your Java code quality. Built for students and developers.

## How to Use

1. Download the files
2. Run Main.java
3. Check your Java file for issues

## Features
- Checks code quality
- Finds common Java mistakes
- Easy to use
